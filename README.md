# Проект по развертыванию сервиса с применением `mlops`

При запуске проекта сервис позволяет запустить:
- `airflow` для планирования задач и пр.
- `mlflow` для логирования экспериментов 
- `hadoop` для загрузки/чтения через PySpark с hadoop
- `jupyter` для ведения тетрадки в момент обучения моделей

Перед запуском проекта необходимо указать:
>- `AWS_ACCESS_KEY_ID` в .env с S3
>- `AWS_SECRET_ACCESS_KEY` в .env с S3

В папке `dags` расположены некоторые просты dag`и и тетрадки
